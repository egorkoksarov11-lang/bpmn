# Испытания v23.4: построение только по связям

Проверены четыре новых схемы: полное бизнес-XML, DI-идентичность, роли, документы, все условия и связи сохранены. 183 теста прошли (175 v23 и 8 исходных v22). Входы побайтово неизменны. `bpmn-moddle` импортировал четыре входа и четыре финальных результата без предупреждений. Код v22 не менялся.

Наименования операций, ролей и переходов, номера шагов и смысловые слова не участвуют в группировке, выборе основного пути и структурного порядка. Текст сохраняется для отображения и расчёта размеров. Замена всех подписей тремя независимыми способами дала одинаковые структурные результаты на всех четырёх процессах — 12 проверок. Входы не менялись.

## Протокол и практические пределы

Четыре входа — последние сохранения четырёх пользовательских сессий, подготовленные и проверенные по хешам ранее. Бизнес-XML каждого выхода полностью совпадает с выбранным входом. Полное удаление исходных позиций, размеров, маршрутов, подписей и порядка дорожек до генерации проверено отдельно.

Первичная генерация: 60 секунд на маршрутизацию кандидата и 200 секунд поиска, затем локальные и групповые проверки. Для S2 дополнительно построена новая графовая альтернатива из того же заново очищенного входа, чтобы проверить согласованный выбор по общей оценке; архивная схема и ручная геометрия в генерацию не подставлялись. Для S4 дополнительно проверены расписание разных семейств и исправленная защита полного пути перед разрывом циклов; конечная схема заново построена с нуля после этого исправления и выбрана по общей оценке среди двух новых графовых построений. В отдельном структурном сравнении защита восстановила 44 макрогруппы вместо 29, без чтения подписей. После построения выполнен отдельный завершающий проход по уже проверенным автоматическим выходам. Все принятые изменения проходят независимый контроль полного текста, подписей, геометрии, семантики и DI.

Временные бюджеты мягкие на границах обязательных проверок; некоторые эксперименты пересекались по времени. Скорость версий не сравнивается. Для сложной схемы поиск может превысить общий бюджет до получения первого пригодного результата. Корпус использовался в разработке; обобщение на независимые процессы не доказано.

Перестройка ограничена числом соседей, количеством затронутых связей и бюджетом. Не все возможные композиции рассматриваются. Проверенный вариант сохраняется при отсутствии выигрыша. Эти ограничения остаются, даже когда запрещённые текстовые подсказки полностью исключены.
