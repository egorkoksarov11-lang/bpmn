# Решения

1. Frozen v4 остаётся единственным источником актуальной модели. Исходники, роли, названия, типы, условия, документы и переходы не меняются.
2. Читаемость текста и отсутствие коллизий — условия допуска, а не пожелания после выбора геометрии.
3. Не уменьшать шрифт, не обрезать названия и не удалять документные связи ради компактности.
4. Исправить подсчёт пересечений в вершинах сетки и не считать законное соединение двух стрелок на общем узле ошибкой.
5. При повторной маршрутизации сохранять только улучшения оценки.
6. Широкий A* проверяет все фигуры, ограниченный — только гарантированно покрытую область. Все финальные пути проверяются на полном наборе препятствий.
7. Не выдавать компактную пропорцию за читаемую A4-схему. На v4 более просторный вариант существенно яснее компактного.
8. Все исходные файлы v22 сохраняются побайтово. Старый результат v23 хранится как регрессионный fixture.
9. Результат — experimental readability revision 23.1.1.dev0, не завершённый универсальный A4 solver и не обещание глобального оптимума.

## Разработка r3: ориентация решения по всем внешним связям

Добавлен эксперимент с четырьмя ориентациями пары задача/решение. Поворот геометрии пары не поворачивает текст, не меняет типы узлов и не переносит подписи между рёбрами. При вертикальной компоновке увеличивается ряд целиком, чтобы последующие узлы и документы не накладывались на новый шлюз. Оценка учитывает все связи обоих узлов, а не только короткую внутреннюю стрелку.

Прокси-оценка не является итоговым критерием. Все предложения проходят полную трассировку, измерение текста, расстановку подписей, semantic diff и DI freeze. Исходные четыре варианта не удалены из поиска. Для воспроизводимого сравнения API поддерживает `HumanStyleBackend(orient_decisions=False)`, CLI — `--no-decision-orientations`.

Библиотека крупных сценарных шаблонов, полноценное снятие блокировки display backbone и диагональная трассировка association пока не интегрированы. Аналитический детектор циклов в tools остаётся отдельным инструментом. Изменение ограничено первым проверяемым экспериментом из исследования.

Первый полный эксперимент без ограничения роста выбрал вариант с 50 контактами, 169 изгибами и габаритом 2957,5×2485, что хуже предыдущего компактного результата по площади. Поэтому добавлена граница пропорций из профиля референсов и опциональный повторно проверяемый incumbent. Он не является новым источником бизнес-логики и не заменяет frozen v4. Подробности сравнения фиксируются в DEVELOPMENT_R3.md.

## Приоритет пользователя: компактность без пучков и скачков чтения

После уточнения пользователя выбор больше не сводится к contacts×100 + bends×2. Введён `balanced-readability-v1`: нормированные контакты, длина близких параллельных участков, локальная плотность потоков, тяжесть длинных переходов к следующим шагам, изгибы и ограничение чрезмерной площади. Пороговые значения и веса — открытая инженерная настройка, а не обученная модель предпочтений.

Возвраты для оценки непрерывности определяются по доминированию в графе, без анализа названий и знака Δx; они учитываются с меньшим весом. Ни одно ребро не удаляется. Маршрутизатор human backend штрафует тесное параллельное ведение и пересматривает перегруженные коридоры даже без пересечений. Раньше такие линии могли не попадать в повторную трассировку. Пространственный индекс ускоряет оценку стоимости без исключения геометрических проверок.

Ориентационные эксперименты могут запускаться через `--orientations-only --incumbent ...`: сохраняется проверенный исходный вариант, а перестраиваются четыре ориентированных предложения. Обычный режим продолжает сравнивать базовые и ориентированные варианты. Все trade-off показатели выводятся отдельно; увеличение пересечений или длин переходов не скрывается за одним итоговым баллом.
