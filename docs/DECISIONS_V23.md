# Решения

1. Frozen v4 остаётся единственным источником актуальной модели. Исходники, роли, названия, типы, условия, документы и переходы не меняются.
2. Читаемость текста и отсутствие коллизий — условия допуска, а не пожелания после выбора геометрии.
3. Не уменьшать шрифт, не обрезать названия и не удалять документные связи ради компактности.
4. Исправить подсчёт пересечений в вершинах сетки и не считать законное соединение двух стрелок на общем узле ошибкой.
5. При повторной маршрутизации сохранять только улучшения оценки.
6. Широкий A* проверяет все фигуры, ограниченный — только гарантированно покрытую область. Все финальные пути проверяются на полном наборе препятствий.
7. Не выдавать компактную пропорцию за читаемую A4-схему. На v4 более просторный вариант существенно яснее компактного.
8. Все исходные файлы v22 сохраняются побайтово. Старый результат v23 хранится как регрессионный fixture.
9. Результат — experimental readability revision 23.1.1.dev0, не завершённый универсальный A4 solver и не обещание глобального оптимума.
