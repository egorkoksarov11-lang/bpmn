# v23.4.2 — вход JSON и YAML

Новый входной слой преобразует строго описанный граф в BPMN, затем вызывает прежний `pipeline.main`. Расстановка, маршрутизация, критерии выбора кандидата, политика документов и проверки семантики не изменены. Для BPMN аргументы передаются без преобразования.

Входы: `.bpmn`, `.json`, `.yaml`, `.yml`, `.ylm`; UTF-8 с допустимым BOM. [Структура и ограничения](../desktop/INPUT_FORMAT.md), [рабочий JSON](../desktop/example.json), [рабочий YAML](../desktop/example.yaml). Первая страница приложения показывает все поля, правила идентификаторов, типы узлов, направление информационных связей и примеры условий. Примеры можно скачать из самого локального интерфейса.

Преобразование сохраняет идентификаторы и названия, типы узлов, принадлежность ролям, все переходы, условия formalExpression, переходы по умолчанию, документы/хранилища и направление ассоциаций. Ничего не выводится из названий или порядка элементов. Неизвестные поля/типы, дубли ключей/идентификаторов и неверные ссылки отклоняются до компоновки. YAML обрабатывается SafeLoader; якоря и псевдонимы запрещены.

`input_model.bpmn` содержит техническую геометрию для контракта движка: режим scratch полностью удаляет её перед планированием. Бизнес-XML результата проверяется против этого промежуточного BPMN. Соответствие исходной структуре проверяет адаптер и его тесты; неподдерживаемые поля нельзя незаметно потерять. Наличие условий в модели не делает генератор средой исполнения BPMN.

В ZIP результата JSON/YAML входят исходный файл, промежуточный BPMN, отчёт импорта с SHA256, схема и обычные отчёты. Исходный файл не перезаписывается. У CLI доступны те же параметры поиска и компоновки:

```bash
python run_v23.py --input desktop/example.json --output-dir result --layout-engine scratch --candidate-timeout 60 --search-seconds 200
python desktop/app.py --input desktop/example.yaml --results results
```

Проверки: 216 тестов движка, адаптера и интерфейса прошли; полная генерация JSON/YAML в чистом окружении завершена; подтверждена идентичность нормализованного BPMN для двух примеров; промежуточные, итоговые и модель с условиями/хранилищем импортированы через bpmn-moddle без предупреждений. Распакованный ZIP отдельно проверен в каталоге с пробелами и кириллицей, включая целостность архива результата и его SHA256-манифест.

На Windows x64 прошли установка с нуля, генерация из BPMN/JSON/YAML и 33 теста адаптера и интерфейса: [успешный запуск Actions](https://github.com/egorkoksarov11-lang/bpmn/actions/runs/42211903294). Результаты трёх генераций доступны в артефакте `windows-desktop-smoke`. ARM64 отдельно не проверялась.

Исторические результаты качества схем остаются в отчётах v23.4; новый формат входа сам по себе не улучшает качество расположения. Профиль JSON/YAML ограничен одним процессом, ролями и перечисленными типами узлов; произвольный BPMN XML обратно в JSON не экспортируется.
