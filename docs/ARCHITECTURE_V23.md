# Архитектура улучшения читаемости

Исходный src/v22 неизменён. Все новые алгоритмы — src/v23/bpmn_v23.

- placement.py: исходное размещение, расширенное размещение с одинаковыми измеренными задачами, два варианта сворачивания внутри целых дорожек. Порядок исходной DI — подсказка для стабильности, а не бизнес-правило. Имена и ID процессов не зашиты в алгоритм.
- router.py: ортогональная трассировка без совпадающих сегментов, варианты портов, ограниченный и широкий A*, повторная прокладка наиболее конфликтных связей. Принимаются только улучшения общей оценки контактов/изгибов/длины.
- quality.py: пересечения в вершинах ломаных и неоднозначные касания; истинное соединение у общего семантического узла разрешено. Разбиение сегмента не скрывает пересечение.
- contours.py: точное примыкание к ромбам/эллипсам; прямоугольники используются как препятствия при поиске.
- typography.py, assets/: один шрифт Open Sans и измерение полного текста через Pillow; перенос длинных слов без потери букв. Лицензия шрифта включена.
- labels.py: подбор положения и ширины подписи без уменьшения шрифта, привязка к собственному узлу/стрелке, пространственный индекс препятствий. Не добавляет семантические associations.
- render.py: SVG по сохранённой DI, полный текст, встроенный шрифт; обозначения шлюзов сохраняют тип. Полная нотация специальных событий за пределами проверенного профиля не заявлена.
- search.py: пять кандидатов, проверка семантики и DI whitelist каждого кандидата, rejection небезопасных/нечитаемых результатов, выбор лучшего среди завершённых.
- freeze.py: разрешены координаты, размеры, waypoints и BPMNLabel; остальная структура DI неизменна.
- pipeline.py: preflight, сохранение источника, staged execution, повторный parse и независимые проверки, отчёты и выдача.

Лимит по умолчанию 150 секунд на весь кандидат (до пяти кандидатов). Можно изменить через --candidate-timeout 1..600. Тайм-ауты сохраняются в отчёте, найденный безопасный вариант не теряется. При достаточном времени порядок поиска детерминирован; при разных тайм-аутах набор завершённых кандидатов может различаться.

Гарантия семантики основана на сравнении всего canonical XML без BPMNDiagram, отдельно проверяется неизменность DI-привязок и флагов. Проверка не доказывает правильность самого зафиксированного процесса.

Публикация файлов по отдельности, не транзакция всего каталога. Использовать отдельные output-dir для параллельных запусков. bpmn-auto-layout/ELK/libavoid не интегрированы; это Python backend с переиспользованием безопасных низкоуровневых компонентов v22.
