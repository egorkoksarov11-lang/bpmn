# r5 — локальные сценарные участки и их интерфейсы

Добавлен экспериментальный режим --scenario-blocks. Он распознаёт небольшие естественные циклы по доминированию в графе, без слов в названиях и координат, учитывает их компактность и пробует перемещать группу совместно. Макроузлы могут включать пару задача/шлюз; это внутреннее представление размещения, без добавления subprocess или изменения BPMN.

Для каждой группы сохраняются исходные ID всех граничных рёбер и их sourceRef/targetRef. В №08 найдено 12 кандидатов по 2–6 макроузлов. У одного из них десять внешних связей. Большие циклы не сворачиваются в один блок. Циклы с несколькими входами не принуждаются к шаблону естественного цикла. Вложенные/пересекающиеся группы участвуют как мягкие ограничения, а не независимые семантические свёртки.

Человек учитывает не только близость внутри участка, но и удобство его подключения к соседям. Эксперимент подтверждает важность этого различия:

| Вариант | Контакты | Изгибы | Балл balanced-readability-v1, меньше лучше |
|---|---:|---:|---:|
| Исходный проверенный r4 | 40 | 199 | 3,939774 |
| Группы, один ряд второстепенных дорожек | 51 | 201 | 4,435607 |
| Группы, два ряда | 61 | 213 | 4,841714 |

Оба новых предложения прошли технические проверки и сохранили семантику, но не выиграли по общей оценке. Поэтому основная схема не заменена. Само по себе сжатие внутреннего цикла пока недостаточно: необходимо лучше выбирать форму группы и точки подключения всех внешних связей. Это ограничение прототипа, а не доказательство невозможности улучшить эти участки.

Режим выключен по умолчанию; --scenario-blocks автоматически включает перестановку основной цепочки. Порядок чтения внутри дорожек и роли сохраняются. Доступны совместные перемещения группы и отдельных узлов с повторной проверкой всего результата. Документы следуют за своими операциями, но отдельная оптимизация общего документа по всем потребителям пока не реализована.

```bash
python run_v23.py --input inputs/benchmark/process_08_v4_frozen.bpmn \
  --output-dir experiment-r5 --candidate-timeout 120 \
  --incumbent output/process_08_v23.bpmn --scenario-blocks --no-decision-orientations
```

Контрольный прогон занял около 150 секунд. Полный набор: 67 тестов прошли. Четыре новые регрессии проверяют граничные связи, отказ от ложного шаблона для многовходового цикла, ограничение размера группы и сохранение порядка/исходных данных при совместных перемещениях. Semantic diff и DI freeze = 0. Текущая опубликованная схема остаётся r4 с 40 контактами.
