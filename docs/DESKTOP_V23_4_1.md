# Пакет самостоятельного запуска v23.4.1

Назначение: распаковать исходники, запустить `START_WINDOWS.cmd`, дождаться локальной установки и выбрать BPMN в браузере. Установка не требует Python, Node.js или прав администратора на исходном компьютере. Рекомендуемая платформа — Windows 10/11 x64; предусмотрена ARM64-ветка загрузки.

Состав: код v23 и необходимые пакеты неизменённого v22, шрифт с лицензией, адаптер ELK, зафиксированные npm/Python-зависимости, PowerShell-установщик, локальный веб-интерфейс и упаковщик. В пакет не включены пользовательские процессы, офисные документы, исходные архивы, виртуальные окружения и node_modules.

Проверки в среде Linux:

- 188 тестов движка и интерфейса прошли; пять новых тестов проверяют успешный процесс, ошибку движка, HTTP-доступ/загрузку/обход путей, Windows-ветку таймера и состав ZIP.
- В чистое окружение установлены только `lxml==6.0.2` и `Pillow==12.0.0`; тестовая схема построена через `desktop/app.py --input` с нуля, семантический diff равен нулю.
- Пакет распакован в путь с пробелами и кириллицей. npm-зависимости установлены из lock-файла отдельно от рабочего каталога; проверяется запуск именно распакованного кода.
- ZIP проверяется на CRC; SHA256 каждого вложенного файла записан в `MANIFEST.sha256.json`. SHA256 самого ZIP опубликован рядом.
- Адреса Windows-архива uv и контрольных сумм Node.js доступны. Хеши uv зафиксированы в установщике; Node.js проверяется по официальному SHASUMS256.txt.

На Windows x64 успешно прошли чистая установка зависимостей, генерация схемы с нуля и все пять тестов интерфейса: [запуск GitHub Actions](https://github.com/egorkoksarov11-lang/bpmn/actions/runs/41630198857). Результаты тестовой генерации приложены к этому запуску как `windows-desktop-smoke`.

Ограничения: ARM64 не проверяется отдельным runner. Кооперативный Windows-таймер не прерывает произвольный блокирующий нативный вызов; вызов Node имеет собственный тайм-аут. Бюджет поиска не ограничивает полное время генерации.

Алгоритм размещения и его критерии сохранены. Изменение движка в этой версии — переносимая оболочка ограничения времени кандидата вместо отсутствующего в Windows SIGALRM. При неуспехе приложение показывает журнал и не предлагает непроверенную схему. Уровень сходства с ручными эталонами не повышается одной упаковкой.
