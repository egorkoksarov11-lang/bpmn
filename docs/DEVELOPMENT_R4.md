# r4: совместное размещение основных шагов и ответвлений

Экспериментальный режим --repack-spine разрешает перемещать основные шаги вместе с корректирующими ответвлениями. Порядок основных шагов внутри каждой дорожки сохраняется; исполнители, узлы и связи не изменяются. Увеличен вес близости последовательных шагов и длинных переходов при поиске размещения. На №08 переставлено 14 элементов основной цепочки.

Дополнительно заголовки дорожек включены в препятствия трассировщика и финальной доводки. Раньше такие нарушения только обнаруживались после прокладки. Первый кандидат с 43 контактами был отклонён из-за прохода через заголовки. После исправления получен и проверен новый результат.

| Показатель | r3 | r4 |
|---|---:|---:|
| Контакты | 60 | 40 |
| Изгибы всех связей | 200 | 199 |
| Длинные переходы | 33 | 31 |
| Тяжесть длинных переходов | 1,361593 | 1,356108 |
| Избыточная локальная плотность | 0,065178 | 0,055430 |
| Пиковое число потоков в ячейке | 8 | 7 |
| Индекс тесных параллельных участков | 0,035540 | 0,047757 |
| Габарит DI | 2957,5×2181 | 3240×2003 |

Площадь выросла примерно на 0,6%. Близкое параллельное ведение немного увеличилось в абсолютном выражении; это не скрывается. Против раннего r2 (0,464144) индекс всё ещё значительно ниже. Функция выбора не означает измеренную субъективную оценку человека.

Semantic diff = 0, DI freeze = 0. Не найдено наложений фигур, проходов через фигуры/заголовки/подписи, общих наложенных сегментов и обрезанного текста. Формат остаётся экспериментальным: пересечения есть, читаемая печать целиком на A4 не достигнута.

Проверки: 63 теста, включая три регрессии перестановки основной цепочки. Проверенный контрольный прогон после исправления заголовков изолировал семейство secondary_rows=1; обычный режим --repack-spine рассматривает два семейства рядов. Полного перебора всех возможных сценарных блоков нет. Крупные шаблоны проверок и согласований пока не встроены в layout; этот шаг снимает ограничение прежнего размещения основной цепочки.

```bash
python run_v23.py --input inputs/benchmark/process_08_v4_frozen.bpmn \
  --output-dir output-r4 --candidate-timeout 120 \
  --incumbent examples/process_08_r3.bpmn --repack-spine --no-decision-orientations
PYTHONPATH=src/v23:src/v22 python -m pytest tests src/v22/tests -q
```

Прежний режим остаётся доступен без --repack-spine. Все новые варианты повторно трассируются и проходят полный аудит; ранее проверенный incumbent сохраняется, если новый кандидат не лучше по текущей политике. Ограничения времени A* могут влиять на координаты и завершённость кандидатов.
