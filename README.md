## Запуск

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run_v23.py --input inputs/benchmark/process_08_v4_frozen.bpmn --output-dir output
PYTHONPATH=src/v23:src/v22 .venv/bin/python -m pytest tests src/v22/tests -q
```

Python ≥3.10; зависимости lxml, Pillow и pytest. Шрифт Open Sans и его лицензия включены. После установки зависимостей сеть и Graphviz/Node не нужны. Опция `--candidate-timeout 60` задаёт секунды на каждый кандидат; по умолчанию 150.

## Состав

- `src/v22` — исходный код и референсы v22; код сохранён без изменений.
- `src/v23` — новый алгоритм, рендерер и независимые проверки.
- `inputs/benchmark` — frozen v4; `inputs/process` — историческая v2 для регрессий.
- `tests` — регрессии и результаты испытаний.
- `docs` — архитектура, решения и ограничения.
- `output` — актуальные проверенные артефакты.

DOCX/XLSX и исходные архивы форм не включены в публичную поставку. Они не требуются для DI-only компоновки зафиксированного BPMN. Это отдельная экспортная поставка; локальная история с исходными офисными документами не публикуется.
