# Промежуточная компоновка по образцам

Это результат исследования и экспериментальной локальной реализации, НЕ финальная версия. Основная ветка и основной output пока не заменены. Код нового backend ещё проходит интеграцию; содержимое этой папки — проверенный снимок артефактов, а не обещание воспроизводимости новым алгоритмом из текущего стабильного кода ветки.

Изучены 32 примера, измерены 506 задач. Медианный размер задачи — 195×80, медианный промежуток — 40, медианная пропорция — 2.13. Распознаны 194 пары «операция → решение». Шрифт образцов автоматически не восстановлен; для целевой схемы выбрано 13 px с проверкой полного текста.

## Что изменилось

- Пары «операция + решение» размещаются совместно.
- Основной сценарий выстраивается по реальным переходам; ветки исправления размещаются отдельно рядом с затронутыми шагами.
- Высоты дорожек зависят от количества работы. Вертикальный порядок ролей подбирается по передачам; исполнитель операции не меняется.
- Для стрелок введён видимый зазор от рамок объектов.
