# Промежуточная компоновка r2

49 контактов линий; размер 2962 × 2105; семантических изменений 0. Наложений блоков, проходов линий через блоки и коллизий подписей не обнаружено. Не финальный релиз: пересечения остаются, печать всей схемы на A4 слишком мелкая.

SVG и BPMN находятся в этой папке. Для скачивания откройте файл и нажмите Download raw file.
