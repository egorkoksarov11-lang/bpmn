# Актуальная задача: построение с нуля

Строить компактные и читаемые схемы по бизнес-графу, ролям, типам узлов и полным названиям. Исходные координаты, размеры, маршруты и Bounds подписей не должны попадать в планировщик. Референсы использовать для изучения общих правил и последующего сравнения.

Сохранять полное бизнес-XML: роли, имена, типы, условия, документы, базы и каждую связь. При наличии DI сохранять идентичность существующих DI-объектов. Не заменять process_08_v4_frozen другой моделью. V22 неизменна. Все результаты писать отдельно от входов.

Цель: операции идут последовательно без лишних изгибов; документы и базы отдельно и близко к связанным шагам; полные подписи подстраиваются по реальным размерам текста. Баланс компактности, контактов, плотности и длины переходов важнее одного улучшенного балла.

Обязательные проверки: semantic diff = 0, DI freeze, полный видимый текст, порты, зазоры и пересечения с объектами; отдельный тест полного сброса геометрии. Не скрывать неудачи и ухудшения. Процент визуального сходства нельзя выводить из синтетического балла.

Запуск: npm ci; python run_v23.py --input inputs/benchmark/process_08_v4_frozen.bpmn --output-dir scratch-result --layout-engine scratch --candidate-timeout 30
