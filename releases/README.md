# Генератор для самостоятельного использования

[Скачать BPMN Generator v23.4.1 для Windows](https://raw.githubusercontent.com/egorkoksarov11-lang/bpmn/main/releases/BPMN_Generator_Windows_v23_4_1.zip).

Распакуйте ZIP целиком, дважды нажмите `START_WINDOWS.cmd`, дождитесь установки, выберите `.bpmn` и нажмите «Создать схему». Получите BPMN, SVG и отчёты в новой папке `results`. Python и Node.js устанавливаются автоматически внутри пакета, права администратора не требуются.

[Подробная инструкция](../desktop/README.md) · [Проверки и ограничения](../docs/DESKTOP_V23_4_1.md) · [Проверка Windows](https://github.com/egorkoksarov11-lang/bpmn/actions/workflows/desktop-windows.yml).

Полный код включён в ZIP. Исходные пользовательские процессы в архив не включены. Для первой установки нужен интернет; обработка BPMN локальная.
