# Генератор для самостоятельного использования

[Скачать BPMN Generator v23.5.1 для Windows](https://raw.githubusercontent.com/egorkoksarov11-lang/bpmn/main/releases/BPMN_Generator_Windows_v23_5_1.zip).

Исправлен ложный отказ collaboration_geometry_rejected: пустые углы прямоугольников вокруг ромбов/эллипсов больше не считаются занятой фигурой. Настоящие наложения продолжают отклоняться. При ошибке показываются конкретные проверки и предлагается полный geometry_error.json.

Распакуйте новый ZIP целиком в отдельную папку, запустите START_WINDOWS.cmd, дождитесь установки и выберите исходный BPMN/JSON/YAML. Формат входа не изменён. Поддерживаются один или два процесса с пулами и сообщениями. Старые версии сохранены.

[Исправление и проверки](../docs/FIX_V23_5_1.md) · [Инструкция](../desktop/README.md) · [JSON/YAML v1/v2](../desktop/INPUT_FORMAT.md) · [Пример двух процессов](../desktop/example-collaboration.json).

Полный код включён в ZIP. Пользовательские входные данные и схемы в релиз не включены.
